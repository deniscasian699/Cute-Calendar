# Changelog — Cute Calendar

## [1.2.0] — 2026

### Added
- Supporter Monthly and Yearly subscription tiers
- Remove Ads one-time purchase
- Custom app launcher icons for Supporter users
- Icon chooser in Settings and Premium screen
- Admin code for development and testing
- `BillingManager` fully migrated to RevenueCat v10 API
- GDPR consent controls via Google UMP SDK

### Changed
- Improved banner and native ad loading logic
- Morning reminder now uses redundant alarm chain scheduling
- Calendar grid day cells no longer clip circle on narrow screens
- Theme switcher text truncates correctly on small displays

### Fixed
- Week numbers displaying incorrectly after month navigation
- Selected day circle clipped on narrow screens
- App title emoji truncated on small phones

---

## [1.1.0] — 2026

### Added
- Home screen widgets: Calendar Widget and Events Widget
- Widget midnight auto-update scheduling
- Compact event list toggle in Settings
- First day of week setting (Sunday / Monday)
- Profile name and photo in Settings

### Changed
- Redesigned Settings screen with card sections
- Improved bottom navigation bar

### Fixed
- Morning reminder not rescheduling after device restart
- Events not refreshing after returning from AddEventActivity

---

## [1.0.0] — 2026

### Initial release
- Monthly calendar grid with event dots
- Add, edit, and delete events
- 12 color categories
- Daily 8 AM morning reminder
- Light, Dark, and System themes
- Premium Lifetime in-app purchase
- AdMob banner and native ads with GDPR consent
- Privacy Policy and Terms of Use
