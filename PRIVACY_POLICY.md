## Summary

- All calendar events and preferences are stored **locally on your device**
- Cute Calendar does **not** operate a cloud sync or backup server
- Optional, one-time import reads selected Google calendars already synced to Android; it is not automatic sync
- Advertising (AdMob) is shown to free users after GDPR consent is obtained
- Supporter / Remove Ads purchases remove all advertising
- Purchases are processed by Google Play and verified by RevenueCat
- No analytics SDKs, no crash reporting, no user profiling
- GDPR, CCPA, and U.S. state privacy compliant

---

## Data Stored Locally

- Event title, date, time, duration, location, notes, color category
- One-time imported event details, including repeat information, copied from selected device calendars
- Profile name and profile picture URI
- Theme preference, first day of week, compact view, week numbers
- Morning reminder setting and notification prompt state
- GDPR consent state (`gdpr_consent`)
- Premium status and purchase token
- Selected launcher icon (Supporter feature)

---

## Your Rights

You can delete all local data by:
1. Using the Reset option in the app (Settings → Danger Zone)
2. Clearing app data: Android Settings → Apps → Cute Calendar → Storage
3. Uninstalling Cute Calendar

For advertising data, use the Ad Privacy Settings in the app or contact Google.
