# Contributing — Cute Calendar

Thank you for your interest in Cute Calendar!

Cute Calendar is a **proprietary, closed-source** Android application. The source code is not publicly available for contribution.

## How You Can Help

### 🐛 Report Bugs
Use our bug report website: **[bugs.rdcapps.com](https://bugs.rdcapps.com/)**
Or open a GitHub issue using the Bug Report template.

### 💡 Suggest Features
Open a GitHub issue using the Feature Request template.

### ⭐ Support Development
The best way to support Cute Calendar is to:
1. Leave a review on [Google Play](https://play.google.com/store/apps/details?id=com.cutecalendardc.app)
2. Purchase Premium Lifetime for customization, Remove Ads, or a Supporter subscription
3. Share the app with friends and family

### 🌍 Translations
If you'd like to help translate Cute Calendar into your language, please contact us at [support@rdcapps.com](mailto:support@rdcapps.com).
