# Security Policy — Cute Calendar

## Supported Versions

| Version | Supported |
|---|---|
| Latest (Google Play) | ✅ |
| Older versions | ❌ — please update |

## Reporting a Vulnerability

If you discover a security vulnerability in Cute Calendar, please report it **privately** — do not open a public GitHub issue.

**Contact:** [support@deniscasian.com](mailto:support@deniscasian.com)  
**Subject line:** `[SECURITY] Cute Calendar — <brief description>`

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Your suggested fix (optional)

We aim to acknowledge reports within 5 business days and resolve confirmed vulnerabilities as quickly as possible.

Thank you for helping keep Cute Calendar safe.
